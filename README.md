# Student Helper Bot

## Описание
Лендинг с чат-ботом для студентов. Отвечает на вопросы о учебе.

## Технологии
- Python
- Flask
- HTML/CSS
- JavaScript
- OpenRouter API

## Как запустить
1. Установить зависимости: `pip install flask requests`
2. Запустить: `python app.py`
3. Открыть: `http://127.0.0.1:5000`
